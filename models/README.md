# Sticker model

U2NetP (U-2-Net) model by Xuebin Qin and contributors; ONNX conversion distributed by the rembg project by Daniel Gatis and contributors.

Download with `python scripts/download_sticker_model.py`. Model URL is fixed in that script; SHA-256: `309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`.

Source repositories: https://github.com/xuebinqin/U-2-Net and https://github.com/danielgatis/rembg .

See ../third_party/U2NET-LICENSE.txt (Apache-2.0) and ../third_party/rembg-LICENSE.txt (MIT). The inference adapter and white-outline composition are implemented for this app; no rembg package is required.
